# Java 21

Fork the repository and edit the selected starter in place. Each challenge uses
a package below `dev.ruben.algorithms` and has matching JUnit 5 tests.

The project requires JDK 21 or newer.

```text
starters/src/main/java/                   # Shared tree edited for practice
solutions/src/main/java/                  # Reference implementations
tests/src/test/java/                      # Contract tests
```

Run the FizzBuzz practice test from `languages/java`:

```bash
mvn -Dtest=FizzBuzzTest test
```

Tests target starters and are intentionally red while the exercise is
incomplete. Reference implementations stay in `solutions/`; verify them with
the maintainer procedure in [`docs/solution-review.md`](../../docs/solution-review.md).
