# FizzBuzz

`func FizzBuzz(n int) []string` devuelve una cadena por cada valor desde `1`

Usa un `switch` sin etiqueta para comprobar primero la regla de divisibilidad
combinada. `strconv.Itoa` convierte los valores normales en cadenas decimales.
El algoritmo tarda O(n) y usa O(n) de espacio para el resultado.
