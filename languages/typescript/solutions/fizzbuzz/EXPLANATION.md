# FizzBuzz

`fizzBuzz(n: number): string[]` builds a typed string array with one entry for
each value from `1` through `n`.

Check the combined divisibility rule first, then use `value.toString()` for
ordinary numbers. The algorithm runs in O(n) time and uses O(n) space.
