# FizzBuzz

`fizzBuzz(n: number): string[]` construye un array tipado de cadenas con una
entrada para cada valor desde `1` hasta `n`.

Comprueba primero la regla de divisibilidad combinada y usa `value.toString()`
para los números normales. El algoritmo tarda O(n) y usa O(n) de espacio.
