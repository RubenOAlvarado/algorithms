# TypeScript

Fork the repository and edit `starters/<challenge>/` in place. Tests target the
starter and are intentionally red while it remains incomplete.

```bash
npm install
npm test -- tests/fizzbuzz.test.ts
```

Run these commands from `languages/typescript`. Edit the matching starter until
its contract test passes. Reference solutions belong in `solutions/<challenge>/`
and use the maintainer procedure in
[`docs/solution-review.md`](../../docs/solution-review.md). New challenges do
not require another `package.json` or `tsconfig.json`.
