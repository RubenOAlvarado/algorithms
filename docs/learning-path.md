# Learning path

This path orders challenges by concepts rather than alphabetically. Complete a
challenge when you can explain the approach, implement it, test edge cases, and
state its time and space complexity.

## 1. Programming foundations

Focus: variables, conditionals, loops, integer operations, and simple input
validation.

1. [FizzBuzz](../challenges/fizzbuzz/README.md)
2. [Sum of Natural Numbers](../challenges/sum-natural-numbers/README.md)
3. [Count Digits](../challenges/count-digits/README.md)
4. [Sum of Digits](../challenges/sum-digits/README.md)
5. [First Turn in Blackjack](../challenges/first-turn-blackjack/README.md)

## 2. String traversal

Focus: indexes, character classification, transformations, and edge cases.

1. [First Occurrence](../challenges/first-occurrence/README.md)
2. [Vowels Count](../challenges/vowels-count/README.md)
3. [Word Count](../challenges/word-count/README.md)
4. [Capitalize](../challenges/capitalize/README.md)
5. [Length of Last Word](../challenges/length-of-last-word/README.md)
6. [Longest Common Prefix](../challenges/longest-common-prefix/README.md)

## 3. Arrays and two pointers

Focus: in-place modification, left/right indexes, and maintaining invariants.

1. [Reverse String](../challenges/reverse-string/README.md)
2. [Reverse Array in Place](../challenges/reverse-array/README.md)
3. [Palindrome](../challenges/palindrome/README.md)
4. [Merge Strings Alternately](../challenges/merge-strings/README.md)
5. [Chunk Array](../challenges/chunk-array/README.md)
6. [Max Profit](../challenges/max-profit/README.md)

## 4. Hash maps and sets

Focus: membership checks, frequency counters, and time/space trade-offs.

1. [Is Unique](../challenges/is-unique/README.md)
2. [Max Char](../challenges/max-char/README.md)
3. [Valid Anagram](../challenges/valid-anagram/README.md)
4. [Lonely Integer](../challenges/lonely-integer/README.md)

## 5. Stacks

Focus: LIFO behavior and matching nested structures.

1. [Valid Parentheses](../challenges/valid-parentheses/README.md)

The next challenge to add here should be **Min Stack**.

## 6. Recursion and dynamic programming

Focus: base cases, repeated subproblems, memoization, and tabulation.

1. [Factorial](../challenges/factorial/README.md)
2. [Fibonacci](../challenges/fibonacci/README.md)

The next challenges should be **Climbing Stairs** and **Coin Change**.

## 7. Matrices

Focus: rows and columns, boundaries, and multidirectional traversal.

1. [Diagonal Difference](../challenges/diagonal-difference/README.md)
2. [Spiral Matrix](../challenges/spiral-matrix/README.md)

## 8. Interview topics to add

These categories currently have no exercises and are the priority for future
growth:

1. Queues and deques
2. Sorting and binary search
3. Sliding window
4. Linked lists
5. Trees and binary search trees
6. Graphs
7. Heaps and priority queues
